# وكيل — CRM للوكيل العقاري في قطر 🇶🇦

تطبيق ويب يعمل على الهاتف (PWA) لتنظيم عمل الوكيل العقاري: العقارات، العملاء، المواعيد، المطابقة التلقائية، التوجه إلى العقارات، وتحسين الصور. واجهة عربية بالكامل (RTL)، يعمل بدون إنترنت، ويُثبَّت على الشاشة الرئيسية كتطبيق.

## المزايا

| | |
|---|---|
| 🏠 **الرئيسية** | مواعيد اليوم، المتابعات المستحقة، أفضل فرص التطابق، إضافة سريعة، "مسار اليوم" على الخريطة |
| 🏢 **العقارات** | إيجار/بيع، 10 أنواع، 24 منطقة في قطر، مزايا (كهرباء وماء مشمولة، مسبح، إطلالة بحرية…)، حالة (متاح/محجوز/مغلق)، بيانات المالك، بحث وفلاتر وترتيب حسب "الأقرب لي"، عرض على الخريطة |
| 👥 **العملاء** | مراحل البيع (جديد ← تواصل ← معاينة ← تفاوض ← إغلاق)، تذكير متابعة بضغطة (غداً / 3 أيام / أسبوع)، سجل نشاط، استيراد من جهات الاتصال، كشف الأرقام المكررة |
| 🎯 **المطابقة** | تقييم 0–100% بين طلب العميل والعقار (الميزانية، النوع، المنطقة، الغرف، الفرش، المزايا) مع شرح الأسباب، إرسال واتساب برسالة جاهزة، استبعاد "غير مناسب" مع تراجع، عدّاد حيّ للعقارات المطابقة أثناء تعبئة طلب العميل |
| 🧭 **التنقل** | Google Maps / Waze / Apple Maps بضغطة، تحديد الموقع بـ"أنا في العقار الآن" أو على الخريطة أو بلصق رابط، مسار متعدد المحطات لمعاينات اليوم |
| ✨ **تحسين الصور** | تحسين تلقائي عند الإضافة (مستويات، توازن الأبيض، رفع الظلال للغرف الداخلية، الألوان، الحدة)، محرر بقوالب جاهزة (داخلي مضيء، خارجي حيوي، دافئ، نقي)، أشرطة ضبط، تدوير، علامة مائية باسمك، اضغط مطولاً للمقارنة بالأصل. التعديلات غير مدمّرة (يُحفظ الأصل) |
| 📅 **المواعيد** | معاينة / اتصال / اجتماع / توقيع عقد، شريط أيام، تذكير العميل وإبلاغ المالك عبر واتساب، نقل العميل تلقائياً لمرحلة "معاينة" |
| 📤 **المشاركة** | واتساب مباشرة للعميل، أو مشاركة مع الصور عبر قائمة مشاركة الهاتف، نسخ الوصف |
| 💾 **البيانات** | محفوظة على الجهاز (IndexedDB) — تصدير/استيراد نسخة احتياطية JSON تشمل الصور |

## التشغيل

لا يحتاج إلى بناء أو مكتبات — ملفات ثابتة فقط.

```bash
npm start        # خادم محلي على http://localhost:8080
npm test         # اختبارات محرك المطابقة
```

للنشر: ارفع المجلد على أي استضافة ثابتة (GitHub Pages، Netlify، Vercel). يجب أن يكون عبر **HTTPS** لتعمل ميزات الموقع والتثبيت والعمل بدون إنترنت.

على الهاتف: افتح الرابط ← قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**.

## البنية

```
index.html            الصفحة الرئيسية
css/app.css           التصميم (فاتح/داكن، مصمم للهاتف أولاً)
js/app.js             الموجّه وشريط التنقل
js/db.js              التخزين المحلي (IndexedDB) والنسخ الاحتياطي
js/match.js           محرك المطابقة + أدوات الهاتف والموقع (مختبرة)
js/photo.js           معالجة الصور على canvas
js/editor.js          محرر الصور
js/map.js             خرائط Leaflet / OpenStreetMap
js/data.js            المناطق والأنواع والمزايا والمراحل
js/views/*            الشاشات
sw.js                 العمل بدون إنترنت
```
